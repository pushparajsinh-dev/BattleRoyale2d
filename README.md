# BattleRoyale2D

A 2D multiplayer battle royale game
developed using Godot Engine and GDScript.

## Project Overview

- 2D top-down gameplay
- Multiplayer LAN support
- Player movement and shooting
- Weapon and health systems
- Shrinking safe zone
- Last player standing wins

## Technology Stack

- Godot Engine 4
- GDScript
- ENet
- Git and GitHub
